# Tetris Game 🎮

A fun and interactive Tetris game built with C++ and the **SFML** library for graphics. This project demonstrates fundamental game development techniques using Fundamentals of Programming and game loops.

---

## 📋 Features
- Classic Tetris gameplay.
- Modern graphics powered by SFML.
- Scoring system and increasing difficulty.

---

## 🛠️ Getting Started

### Prerequisites
To build and run this project, you'll need:
- A C++ compiler (e.g., GCC, MSVC).
- The **SFML library** (version 2.5 or higher).
